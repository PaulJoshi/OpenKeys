Circular 40px icon-only control; use for back, prev/next, favorite, share and transport (play/pause) buttons.

```jsx
<IconButton icon="heart" label="Save song" />
<IconButton icon="play" label="Play" variant="inverse" size={56} />
```

- Variants: `soft` (soft cloud, default), `ghost` (transparent, in nav bars), `onImage` (white), `inverse` (ink — the main transport button only).
