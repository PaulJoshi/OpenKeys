Pill-shaped call-to-action; use primary for the one main action per viewport, secondary beside it, onImage on photography.

```jsx
<Button>Start lesson</Button>
<Button variant="secondary">Not now</Button>
<Button variant="onImage" iconRight="arrow-right">Explore</Button>
```

- Sizes: `sm` (14px, 8/16 padding), `md` (16px, 48px tall, 32px sides — default), `lg` (24px campaign CTA).
- Press = "tap collapse" (scale 0.5, opacity 0.5). No hover state by policy.
- Never two ink pills in one fold; never a square button.
