Small label; `promo` is a white hairline pill on imagery, the text variants are container-less inline status.

```jsx
<Badge>New</Badge>
<Badge variant="success">Completed</Badge>
<Badge variant="error">3 missed notes</Badge>
```

- promo: 12px medium, 4/12 padding, 30px radius. Text variants: 14px medium, no background — red/green never get containers.
