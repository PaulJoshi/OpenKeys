Flat song/lesson card for grids and rails; the media is the card.

```jsx
<SongCard title="Für Elise" subtitle="Beethoven · Beginner" meta="4 min" badge="Popular"
  swatches={[{ color: 'var(--ok-accent-purple-soft)', label: 'Classical' }]} />
<SongCard title="Ode to Joy" subtitle="Beethoven · Beginner" meta="Completed" metaVariant="success" />
```

- No padding, radius, shadow or border. Media on soft cloud; 8px between metadata rows. Grid gutters 8px.
