# OpenKeys website — UI kit

Marketing site. Open `index.html`. Nav switches between **Learn piano** (home) and **Why free**; "Start learning" jumps to the app kit.

Home: utility bar + sticky primary nav → full-bleed CampaignTile → "Start with these" 4-up SongCards → 6-up CategoryIconCard strip → 3-up BenefitCards → footer.
Why free: accent campaign tile → two-column statement → FAQ DisclosureRows.

Files: `SiteChrome.jsx` (header/footer), `HomePage.jsx`, `WhyPage.jsx`.

Note: no existing OpenKeys site was supplied; layouts follow the source's category-home and membership-page patterns. The hero shows an ink fill where campaign photography belongs.
