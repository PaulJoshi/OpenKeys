# OpenKeys

A free, open-source piano teacher that runs entirely in your browser. It plays pieces with a real
piano sound, listens to you play (microphone or MIDI keyboard), judges what you played, and teaches
with specific, encouraging feedback.

> Work in progress: see `docs/` for decisions and measured accuracy.

```sh
npm install
npm run dev       # http://localhost:5173
npm test          # unit tests
npm run build     # static site in dist/
```
